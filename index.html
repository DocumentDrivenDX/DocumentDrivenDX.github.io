A worked example

From feature spec
to release note.

Design a CSV export from the acceptance criterion through data, storage, actions, and an API. This example illustrates how the pieces fit together.

HELIXcsv-export.md

Define what counts as done.

Write an acceptance criterion a person or an agent can test.

When a date filter is active, the CSV contains only the visible reporting period and starts with column headers.
UMFreport-export.yaml

Describe the data being exported.

Declare a ReportRow with a reporting date, category, and decimal total. Model an ExportJob with a date range, state, and a reference to the report.

Each CSV row must contain a reporting date, a category, and an exact decimal total.
TRUSS · ASHLARRecords and snapshots

Keep job state and reporting data separate.

Track the export job and its link to the report with Truss on PostgreSQL. Read report rows from a published snapshot on Ashlar in Databricks.

Record the snapshot ID with the job so a retry can use the same reporting data.
UMF · WEFTSQL and ORM

Use the same model for queries and typed access.

Use generated Python access to look up a job by key on a supported profile. Run native SQL for a backend-specific read, or use Weft to compile the report’s date-range query into SQL for the chosen backend.

Pass the date range as query parameters and stream the resulting date, category, and total into the CSV.
UMF ACTIONSHost-run saga design

Declare the changes and design for retry.

Declare actions to request the export and mark it ready. The host coordinates the saga across the job store and file storage.

Reserve a job ID, stage the CSV, then mark the job ready. Retry with the same ID. If publication is abandoned, remove the staged file and mark the job failed.
LINTELGraphQL API design

Expose the export job to the client.

Design a GraphQL job status query and a Relay connection for export history around the UMF records. The application handles export requests and authorizes downloads.

Show the job’s state and date range. Offer the CSV download once the job is ready and the requester has access.
INNSIGLEColophon

Record how the note was made.

Attach a short declaration to the release note, with an optional signature for verification.

Mixed authorship. An AI assistant drafted the note. The maintainer checked it against the shipped feature and approved the text.
